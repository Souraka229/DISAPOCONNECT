# DiasporaConnect

**MIABE Hackathon 2026 | Benin - D02 Inclusion financiere & DeFi**

DiasporaConnect revolutionne les transferts d'argent de la diaspora beninoise en reduisant les frais de 7-15% a moins de 1% grace a la blockchain.

## Apercu

Site vitrine et prototype pour DiasporaConnect, une application mobile de transfert d'argent a faible cout destinee a la diaspora africaine.

### Fonctionnalites

- Landing page responsive avec calculateur de transfert interactif
- Comparaison de frais en temps reel (vs Western Union, MoneyGram, banques)
- Showcase des mockups de l'application mobile
- Sections: fonctionnalites, tarifs, securite, FAQ, temoignages
- Aligne sur les ODD 1, 8 et 10

## Demarrage rapide

```bash
# Servir localement
npx serve .
# ou
python3 -m http.server 3000
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## Technologies

- HTML5, CSS3 (pas de framework)
- JavaScript vanilla
- Google Fonts (Inter)
- Design responsive mobile-first

## Contexte

La diaspora beninoise envoie 450-550 millions USD/an. Les frais de 7-15% representent une perte de 70-100 millions USD pour les familles. DiasporaConnect vise a reduire ces frais a moins de 1%.
